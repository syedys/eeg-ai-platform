# EEG AI Platform

A production-style machine-learning portfolio project for processing EEG data and serving seizure-detection predictions.

## Purpose

This project is designed to demonstrate an end-to-end ML workflow, including:

- Data preprocessing
- Model training and evaluation
- Experiment tracking
- A prediction API
- Testing
- Containerisation
- Cloud deployment
- CI/CD
- Logging and monitoring

> This is an educational portfolio project and is not a clinically validated medical diagnostic system.
